Die [**Karte**](https://lebenshilfe.codingforchange.com/admin/map) zeigt für einen
gewählten Tag, welche Kinder an welcher Schule sind und welche Schulbegleitung sie
begleitet – geografisch auf einer Landkarte.

<Frame caption="Die Tagesübersicht auf der Karte">
  <img src="/images/admin/karte.png" alt="Karte" />
</Frame>

## So nutzen Sie die Karte

<Steps>
  <Step title="Datum wählen">
    Stellen Sie über das Feld **Datum** den gewünschten Tag ein.
  </Step>
  <Step title="Einsätze ablesen">
    Die Schulen erscheinen als Punkte auf der Karte. Pro Schule sehen Sie die anwesenden
    Kinder mit ihren zugewiesenen Schulbegleitungen – bei einem **Tandem** sind mehrere
    Schulbegleitungen je Kind sichtbar.
  </Step>
</Steps>

<VideoPlaceholder title="Die Karte nutzen" />

<Note>
  **Krankgemeldete** Kinder werden für den gewählten Tag automatisch ausgeblendet – die
  Karte zeigt also nur die tatsächlich stattfindenden Einsätze.
</Note>

<Tip>
  Punkte erscheinen nur, wenn die Schule eine gültige **Adresse/Standort** hat. Fehlt ein
  Standort, ergänzen Sie ihn im Bereich [Schulen](/admin/schulen).
</Tip>
