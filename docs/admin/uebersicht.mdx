## Rollen: Admin und Owner

Es gibt zwei Verwaltungsrollen:

- **Admin** – kann alle Bereiche verwalten (Kinder, Schulen, Schulbegleiter, Exporte usw.).
- **Owner** – wie Admin, kann zusätzlich in der **Benutzerverwaltung** andere Owner ernennen
  oder entfernen.

<Note>
  Wiederkehrende Bedienelemente: Über **Details bearbeiten** öffnen Sie einen Datensatz,
  über **Löschen** entfernen Sie ihn (jeweils mit Sicherheitsabfrage). Neue Datensätze legen
  Sie über die Schaltfläche oben rechts an (z. B. **Neues Kind anlegen**).
</Note>
