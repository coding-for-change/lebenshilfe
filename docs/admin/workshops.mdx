[**Workshops**](https://lebenshilfe.codingforchange.com/admin/workshops) sind Fortbildungen
für Schulbegleitungen (z. B. „Erste-Hilfe-Schulung"). Angelegte Workshops können Sie bei
einer Schulbegleitung im Schritt **Workshops** zuordnen.

  <img src="/images/admin/workshops.png" alt="Workshops-Übersicht" />
</Frame>

## Einen Workshop anlegen

<Steps>
  <Step title="Neuen Workshop anlegen wählen">
    Klicken Sie oben rechts auf **Neuen Workshop anlegen**.
  </Step>
  <Step title="Name und Beschreibung eingeben">
    Tragen Sie einen **Namen** (z. B. „Erste Hilfe Schulung") ein. Eine **Beschreibung** ist
    optional.
  </Step>
  <Step title="Anlegen">
    Bestätigen Sie mit **Anlegen**.
  </Step>
</Steps>

<VideoPlaceholder title="Einen Workshop anlegen" />

## Übersicht

Die Tabelle zeigt **Name**, **Beschreibung** und das Erstellungsdatum. Über **Details
bearbeiten** passen Sie einen Workshop an, über **Löschen** entfernen Sie ihn.

<Warning>
  Workshops mit bestehenden **Teilnahmen** können nicht gelöscht werden. Entfernen Sie
  zuerst die Teilnahmen oder behalten Sie den Workshop bei.
</Warning>
