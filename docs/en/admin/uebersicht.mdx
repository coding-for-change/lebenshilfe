## Roles: Admin and Owner

There are two admin roles:

- **Admin** — can manage all sections (children, schools, school assistants, exports, etc.).
- **Owner** — like Admin, and can additionally promote or remove other owners in **user
  management**.

<Note>
  Common controls: open a record via **Details bearbeiten**, delete one via **Löschen**
  (each with a confirmation). Create new records with the button in the top right (e.g.
  **Neues Kind anlegen**).
</Note>
