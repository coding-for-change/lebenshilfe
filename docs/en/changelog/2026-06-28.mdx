## New features

**Pools.** Admins can now group multiple children and their Schulbegleiter into a shared **Pool** — useful for settings where a small team of SBs supports several children together rather than 1:1. Open the new **Pools** area from the admin navigation to create a pool, assign a school and Kostenträger, and add children and Schulbegleiter.

Pools come with three things out of the box:

- **A combined Kostenträger export per pool.** From a pool's detail view, choose **Export** to generate the Einsatznachweis covering all children in the pool — for a single month or a month range, in PDF, Excel, or CSV. The export uses the pool's Kostenträger, so you no longer need to run an export per child for shared assignments.
- **A simpler timesheet for Pool-Schulbegleiter.** SBs working in a pool get a streamlined entry sheet: only **Direkt** work (no child selection) and their own sick reporting. Vertretung and Indirekt are hidden, since they don't apply in a pool setup.
- **School-mismatch warnings.** If a child added to a pool belongs to a different school than the pool itself, the detail sheet flags it so you can correct the assignment before exporting.
